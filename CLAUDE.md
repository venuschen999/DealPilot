# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

DealPilot is an AI-powered shopping assistant: users find a product from a photo or text description and compare deals across retailers by price, ratings and overall value. The repository is an early Next.js scaffold; the product is specified in `docs/` and most of it is not built yet.

## Commands

- `npm run dev`: dev server on http://localhost:3000
- `npm run build` / `npm start`: production build and serve
- `npm run lint`: ESLint (`eslint-config-next` core-web-vitals + TypeScript)
- `npm run typecheck`: `next typegen && tsc --noEmit`. `next typegen` must run first because route-aware globals such as `LayoutProps` are generated into `.next/types`.
- `npm run format`: Prettier (write)
- `npm test`: Vitest, run once; `npm run test:watch` for watch mode; `npm run test:coverage` for v8 coverage (70% thresholds on `src/lib/**`)
- Single test file: `npx vitest run src/path/to/file.test.ts`
- Single test by name: `npx vitest run -t "part of the test name"`

Vitest only collects `src/**/*.test.ts(x)` (see `vitest.config.ts`); the `@/*` alias maps to `src/*` through `vite-tsconfig-paths`.

## Next.js version

This is Next.js 16 with React 19, whose APIs differ from older versions. `AGENTS.md` (regenerated by `next dev`) says to read the relevant guide in `node_modules/next/dist/docs/` before writing Next.js code and to heed deprecation notices. `next.config.ts` enables `cacheComponents` and `partialPrefetching`, and Tailwind v4 is loaded through the `@tailwindcss/turbopack` loader rule rather than PostCSS.

## Specs (read before building features)

- `docs/PRD.md`: user stories US-1 to US-9 with acceptance criteria, the exact ranking formula and weight presets, AI feature fallbacks, data source rules and non-functional requirements.
- `docs/architecture.md`: system diagram, API route table with access levels, and the Prisma schema (PostgreSQL) for User, WishlistItem, SearchHistory, SearchCache, SourceConfig, ApiUsage and MatchFlag.
- `docs/design/DESIGN.md`: UI source of truth, with design tokens, global components and per-screen specs. Screenshots are in `docs/design/screens/`. The `.dc.html` files in `docs/design/source/` are reference mockups that need a canvas runtime; rebuild them as Next.js + Tailwind components rather than copying markup. `Results.dc.html` contains the reference ranking logic (`renderVals()`).
- `docs/claude-code-setup.md`: how Claude Code permissions and context management are set up for this repo.
