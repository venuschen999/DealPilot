# Mockup source

Exported from the DealPilot design canvas. These `.dc.html` files rely on the canvas runtime (`support.js`, `<x-dc>`, `<sc-for>`, `<sc-if>`, `{{…}}` bindings), so they do not open as working web pages on their own.

Use them as a lookup for exact colors, spacing, copy and markup structure. `Results.dc.html` also contains the reference ranking logic in its `<script>` block. See `../DESIGN.md` for the spec and `../screens/` for rendered images.
